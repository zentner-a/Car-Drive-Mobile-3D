# Car Drive Mobile 3D

Прототип автомобильного раннера для Android: автомобиль движется вперёд, перестраивается между тремя полосами, камера следует за ним, а сегмент окружения повторяется по мере движения.

## Запуск

1. Установите Unity **6000.6.8f1** через Unity Hub. Для Android-сборки нужны Android Build Support, SDK, NDK и OpenJDK.
2. Откройте папку проекта через Unity Hub и дождитесь восстановления пакетов и компиляции. Пакет `com.coplaydev.unity-mcp` загружается из Git, поэтому для первого восстановления нужны Git и доступ к GitHub.
3. Откройте основную сцену `Assets/Scenes/Main.unity` и нажмите Play. При запуске Play Mode редактор использует уровень качества `Mobile`, как Android; после выхода восстанавливается прежний уровень. Для сравнения установите в Game View соотношение сторон тестового устройства. В редакторе доступны свайп мышью и клавиши A/D или стрелки; на устройстве — горизонтальный свайп с отпусканием. `Assets/Scenes/Experimental.unity` — прежняя альтернативная сцена, в сборку не включена.

## Сборка и установка на Android

### Через меню проекта

1. Остановите Play Mode и дождитесь окончания компиляции в Unity.
2. Выберите `Tools → Build Android APK`. Команда при необходимости переключит платформу на Android. Первое переключение может занять несколько минут. Если Unity попросит дождаться перекомпиляции и повторить команду, сделайте это после её окончания.
3. Дождитесь сообщения `Android build result: Succeeded; errors: 0` в Console. Файл сборки: `Builds/CarDrive-test.apk` в корне проекта. Это Development Build: диагностическая консоль доступна при ошибках. Если написано `Unknown` или `Failed`, успешной сборки нет — проверьте сообщения Console.

### Через стандартное окно Unity

1. Откройте `File → Build Profiles`, выберите или добавьте профиль Android и нажмите `Switch Profile`, если он ещё не активен.
2. Убедитесь в списке сцен профиля, что включена основная сцена `Assets/Scenes/Main.unity`. Для диагностической сборки включите `Development Build` в настройках профиля.
3. Нажмите `Build`, выберите путь и имя `.apk`, дождитесь завершения сборки. При выборе `Build And Run` Unity также попробует установить и запустить её на подключённом телефоне.

### Установка готовой APK через USB

1. На телефоне включите параметры разработчика и отладку по USB, разблокируйте телефон и подключите кабель, поддерживающий передачу данных. Если потребуется, выберите режим передачи файлов и подтвердите запрос доверия компьютеру.
2. Откройте PowerShell. В примере ниже указан путь к ADB из установленного на этом компьютере Unity; на другом компьютере замените его на свой путь к `AndroidPlayer/SDK/platform-tools/adb.exe`.

```powershell
$adbPath = 'F:\Program Files\Unity\6000.6.8f1\Editor\Data\PlaybackEngines\AndroidPlayer\SDK\platform-tools\adb.exe'
& $adbPath devices -l
```

В списке должен появиться телефон со статусом `device`. Если список пуст, проверьте кабель, USB-режим и драйвер; если указан `unauthorized`, разблокируйте телефон и подтвердите запрос отладки.

3. Находясь в корне проекта, установите APK командой:

```powershell
& $adbPath install -r '.\Builds\CarDrive-test.apk'
```

Параметр `-r` обновляет уже установленное приложение с тем же identifier, сохраняя его данные. Дождитесь `Success` и при необходимости разрешите установку на телефоне. После этого откройте игру с телефона. Можно также перенести APK на телефон и установить её вручную, разрешив установку из выбранного источника в настройках Android.

Постоянный application identifier ещё не определён; задача записана в [TODO.md](TODO.md). Development APK проверена на Huawei P40 lite E (Android 10). Для Android задан `APP_UI_EDITOR_ONLY`: пакет App UI остаётся доступным в редакторе, но не включается в игру.

## Содержимое

- `Assets/Content/Cars` — исходные модели машин.
- `Assets/Content/Roads` — отдельная модель дороги.
- `Assets/Content/Locations` — модели окружения. Текущий `asset_house 1.fbx` включает дорогу и окружение и повторяется генератором; это не просто отдельное здание.
- `Assets/Prefabs/Player.prefab` — машина с контроллером на корне и визуальной моделью внутри. `Assets/Prefabs/LocationSegment.prefab` — текущая локация с корректирующим поворотом модели внутри; `Assets/Prefabs/RoadSegment.prefab` — отдельная дорога без окружения. `Assets/Scripts` — управление, камера и генератор.
- `Documentation/Screenshots` — локальные рабочие снимки; папка не хранится в Git и может отсутствовать в новом клоне.

В текущей сцене генератор использует явно назначенные машину и шаблон сегмента. Игровые корни префабов имеют единичный масштаб и нулевой поворот; оси проекта: +Y вверх, +Z вперёд, +X вправо, единица соответствует метру. При добавлении машины расположите скорректированную визуальную модель под корнем с `CarController`. При добавлении локации поместите её визуальную модель под корнем с единичным масштабом и нулевым поворотом. Назначьте префаб в `RoadManager` и задайте расстояние между его pivot по оси Z в поле `segmentLength`. Для текущего сегмента оно равно 20; стыковка требует визуальной проверки. Последовательность разных по длине сегментов одновременно пока не реализована.

Основная камера и оба URP-профиля работают без HDR. Постобработка на основной камере отключена: пользователь подтвердил ожидаемый вид в Play Mode и Android. Профиль эффектов сохранён и может использоваться при дальнейшей художественной настройке; при его включении нужно повторно сравнить платформы. Android-ориентация зафиксирована как портретная и проверена на устройстве.

## Зависимости и ограничения

Проект использует Universal Render Pipeline и новый Input System. Пакеты Unity AI и Unity MCP присутствуют в `Packages/manifest.json`; они не требуются для описанных игровых действий и пока сохранены без изменений. Unity восстанавливает версии из `Packages/packages-lock.json`.

Источники и лицензии моделей пока неизвестны и требуют уточнения у автора. Пользователь проверил короткую поездку и перестроение на телефоне; поддержка разных экранов и производительность ещё не проверены полностью. На устройстве без сервисов Google игра запустилась; в Android-журнале остаётся сообщение Unity об отсутствующем `AssetPackManager`, его влияние требует расследования.
